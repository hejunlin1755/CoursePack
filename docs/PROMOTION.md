# CoursePack 零成本推广素材

本文件用于维护不重复、符合社区规则的宣传角度。每个渠道只做一次与受众匹配的首发；除非有重大版本更新，否则不删除重发、不复制同文、不批量私信，也不请求互 Star。

## 发布顺序

1. GitHub：设置 Topics、Social Preview 和最新 Release。
2. 酷安：学生晚上整理书包的真实场景与真机截图。
3. Bilibili：60–90 秒完整操作录屏。
4. V2EX「分享创造」：原生 Android、极小 APK 与无网络权限的技术取舍。
5. 小红书：普通课程表与逐件书包清单的对比演示。
6. 知乎：在“如何避免忘带课本”类问题中披露项目作者身份并提供完整解决方案。
7. Reddit / Show HN：仅在阅读目标社区规则后发布英文技术介绍；不求赞。
8. F-Droid：具备可复现构建条件后提交收录请求。

## 不重复内容角度

- 学生痛点：课程表告诉你上什么，CoursePack 告诉你书包里放什么。
- 隐私：没有 `INTERNET` 权限，课程和清单只保存在手机。
- 体积：原生 Android View，不到 1 MiB 的完整 APK。
- 桌面效率：2×2 与 4×2 小组件直接显示还缺什么。
- 行为模型：已装物品跨日沿用，多余物品提醒拿出。
- 可选随身项：永久物品每天重新打卡，临时物品按准备日出现。
- 设计：Material 3 Expressive、动态色、深色、方向性动画和触感。
- 开发复盘：从学校课表照片迭代到可用 APK。
- 技术拆解：本地持久化、跨日刷新、小组件后台更新。
- 兼容性征集：邀请用户提交 ColorOS、MIUI、One UI 小组件问题，而不是请求 Star。

## 首发文案底稿

### 酷安：实际使用场景

我做了一个完全离线的 Android 书包清单。它不是只显示“明天上什么课”，而是把每个科目的课本、笔记和用品拆成可以逐件勾选的项目；已经放进书包的东西会跨日保留，不需要的东西会提醒拿出来。没有账号、广告、统计 SDK，也没有网络权限。源码和 APK 都在 GitHub，欢迎实际使用后反馈课程表和桌面小组件的问题。

### Bilibili：视频结构

1. 5 秒：普通课程表无法回答“书包还缺什么”。
2. 15 秒：建立科目，并逐格添加需要携带的物品。
3. 15 秒：批量设置节次并排入每周课表。
4. 15 秒：逐件勾选、拿出提醒和完成动效。
5. 10 秒：展示 2×2 与 4×2 桌面小组件。
6. 10 秒：展示 APK 体积、无网络权限和开源地址。

### V2EX：技术角度

标题：分享一个不到 1 MiB、没有网络权限的原生 Android 书包清单

CoursePack 的目标不是再做一个课程表，而是解决“明天到底要把哪些东西放进书包”。项目使用原生 Java/View，没有 WebView 和第三方运行时；科目、课表、逐件清单与书包状态都保存在本机。桌面提供 2×2 和 4×2 小组件，并处理了跨日、重启与时区变化后的刷新。希望征集不同 Android 桌面，尤其 ColorOS、MIUI 和 One UI 的小组件兼容性反馈。
